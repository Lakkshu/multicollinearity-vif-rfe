# 📊 Multicollinearity Analysis using VIF and RFE

This project provides a simple and effective way to detect and handle multicollinearity in datasets using:

- ✅ **VIF (Variance Inflation Factor)**: To identify highly correlated features
- ✅ **RFE (Recursive Feature Elimination)**: To select the most relevant features for your model

---

## 📌 What’s Inside?

- Python script to calculate VIF scores for all numerical features
- Implementation of RFE with any scikit-learn estimator (e.g., Linear Regression)
- Sample usage and results interpretation

---

## 🧠 Why This Matters

Multicollinearity can negatively impact model interpretability and performance. This code helps:

- Identify redundant features
- Improve model performance
- Simplify feature space for better generalization
